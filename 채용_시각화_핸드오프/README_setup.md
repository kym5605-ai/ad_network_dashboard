## 프로젝트 설명 (Custom Instructions 란에 붙여넣기)

```
에브리타임을 레버리지해 캠퍼스픽에서 수익을 만드는 BM 설계 프로젝트입니다.
VINU TEAM 워크숍 4조 과제 중 건우님 담당 파트(수익구조·정량지표)를 심화합니다.

■ 반드시 지킬 것

1. 프로젝트 지식의 context_campuspick_BM.md가 단일 진실 문서(SSOT)입니다.
   작업 전 반드시 읽고, 그 안의 확정 사항과 금지 사항을 따릅니다.

2. 출처가 확인되지 않은 수치를 만들지 않습니다.
   기억에 의존한 통계, 추정한 시장 규모, 임의로 가정한 전환율을 사실처럼 쓰지 않습니다.
   근거가 필요하면 웹에서 확인하고, 확인되지 않으면 "확인되지 않음"이라고 명시합니다.

3. 수치를 쓸 때는 모집단 정의와 비교 기준선을 함께 확인합니다.
   값이 맞아도 프레이밍이 틀리면 잘못된 자료입니다.
   (예: 「대졸자 평균 졸업 소요기간 4년 5.7개월」은 3년제 이하 30.7%가 섞인 가중평균이므로 4년과 직접 비교하면 안 됨)

4. 웹페이지·UI 시안은 .jsx가 아니라 바로 렌더링되는 .html 단일 파일로 제공합니다.
   파일명은 한글이 아닌 영문으로 짓습니다. (한글 파일명은 다운로드가 실패합니다)

5. 이 프로젝트는 취업 컨설팅 시장 진입이 아닙니다.
   우리는 사람이 붙는 코칭이 아니라 정보 열람 구독을 만듭니다.
   컨설팅 시장 프레임으로 논리를 세우지 않습니다.

6. 저는 이 시장의 전문가가 아니고, 자료를 보는 사람 중에는 전문가가 있습니다.
   모든 자료와 논리는 일반 대학생이 봐도 납득할 정도로 명료해야 합니다.
   복잡한 설명이 필요하면 설계가 잘못된 것입니다.

7. 매출 시뮬레이션은 변수를 드러내는 방식으로 만듭니다.
   숫자를 맞히는 것이 아니라 무엇이 매출을 결정하는지 보이게 하는 것이 목적입니다.
```

## 올리지 말 것

## 세션 오픈 순서

1. **지금** — 새 프로젝트 생성 → 컨텍스트 문서 업로드
2. **개발 세션 · PPT 세션 둘 다 지금 오픈**
   - 개발: 확정된 데이터 스키마로 화면 제작
   - PPT: BM이 바뀌어도 안 흔들리는 1단계(배경·근거·디자인)부터 제작
3. **전략 세션**(현재 대화)은 유지하며 남은 결정 진행
4. BM이 확정되면 → PPT 세션에 **2단계 지시문** 전달

> 발표자료는 한 번에 완성하지 않습니다. **확정된 순서대로 쌓습니다.**
> 배경·시장 근거·디자인은 지금 확정이라 먼저 만들 수 있고,
> BM 장표는 나중에 끼워 넣습니다.
